## Acceptance Criteria

1. `notebooks/eda_helpers.py` defines exactly this public surface, with type
   annotations on every signature:

   ```python
   PROVIDERS: dict[str, Provider]          # keyed "es-pnoa"; one entry only

   @dataclass(frozen=True)
   class Provider:                         # endpoints, layer names, advertised
       ...                                 # CRS, epoch layer pattern, expected
                                           # vector attribute names, native
                                           # projected CRS, default GSD, and
                                           # default_view (centre lat/lon plus
                                           # zoom) for the notebook's map

   @dataclass(frozen=True)
   class Fetch:                            # url, status, nbytes, md5,
       ...                                 # elapsed_s, path, error

   def fetch(url: str, params: dict[str, str], out_dir: Path, *,
             timeout: float = 30.0) -> Fetch
   def wms_capabilities(provider: Provider, service: str, out_dir: Path) -> Fetch
   def wms_map(provider: Provider, layer: str, bbox: tuple[float, float, float, float],
               crs: str, size: tuple[int, int], out_dir: Path, *,
               image_format: str = "image/png", transparent: bool = True) -> Fetch
   def wms_feature_info(provider: Provider, layer: str, bbox: ..., crs: str,
                        size: ..., xy: tuple[int, int], out_dir: Path) -> Fetch
   def wfs_buildings(provider: Provider, bbox: ..., crs: str, out_dir: Path) -> Fetch
   def epoch_availability(provider: Provider, bbox: ..., crs: str,
                          years: Iterable[int], out_dir: Path) -> list[dict[str, object]]
   def is_blank_image(path: Path) -> bool
   def image_stats(path: Path) -> dict[str, object]
   def manifest_path(out_dir: Path) -> Path
   def write_summary(rows: list[dict[str, object]], out_dir: Path) -> Path

   # Extent geometry — pure, deterministic, no I/O. Used by the notebook's map
   # selector and by any extent typed in by hand.
   Bbox = tuple[float, float, float, float]

   def to_projected(bbox: Bbox, source_crs: str, target_crs: str) -> Bbox
   def snap_outward(bbox: Bbox, grid_m: float) -> Bbox
   def extent_report(bbox: Bbox, crs: str, *, gsd_m: float,
                     tile_px: int) -> dict[str, object]
   def extent_env_lines(bbox: Bbox, crs: str) -> str
   def save_extent(bbox: Bbox, crs: str, out_dir: Path) -> Path
   ```

2. **No coupling.** `grep -nE "geo_decay_|sys\.path" notebooks/eda_helpers.py`
   finds nothing.

3. **The provider is data.** Every occurrence of `ign.es`, `idee.es`, `cnig`,
   `catastro` and `http` in the module lies inside the source range of the
   `PROVIDERS` assignment. No function body names a host, a layer or an
   attribute of any particular country. The map's opening view is part of the
   entry too (`default_view`), so adding a country does not mean editing the
   notebook.

4. **Nothing raises on a dead host.** `fetch` against an unresolvable URL
   returns a `Fetch` with `error` set, `status == 0`, `md5 == ""` and
   `path is None`, and still appends a manifest row. `epoch_availability` over a
   year range returns one row per year with no exception raised.

5. **The manifest is the audit trail.** `manifest_path(out_dir)` is
   `out_dir / "manifest.csv"`, created with the header
   `timestamp_utc,url,status,nbytes,md5,elapsed_s,error` and appended to — never
   truncated — once per request, including failed ones.

6. **Image checks.** `is_blank_image` returns `True` for a fully transparent
   PNG — the shape a WMS returns for a year it has no imagery for — and for a
   single-colour PNG, `False` for a PNG with more than one distinct pixel value.
   `image_stats` returns, for a small synthetic RGB PNG: `width`, `height`,
   `bands`, per-band `min`/`max`/`mean`/`std`, `saturated_share`,
   `nodata_share` and `gradient_variance` (a numpy sharpness proxy; no OpenCV,
   no SciPy).

7. **`--selftest` runs offline and exits 0**, exercising criteria 4, 5, 6 and 12
   against inputs it builds itself in a temporary directory, and printing one
   line per check. It makes exactly one network attempt, to an unresolvable
   host, and that attempt must not fail the selftest. The geometry checks need
   no network: `pyproj` carries its own grids.

8. **`--check-notebook <path>` exits 0 for a valid notebook and non-zero with a
   reason** for one that fails any of: `nbformat` validation; every code cell
   compiles; every code cell is preceded by a markdown cell; no code cell
   outside the first contains an `http` literal or a coordinate literal; no
   `geo_decay_` import; no absolute path. This is the check handoff 014 is
   verified with.

9. **The `eda` group is optional.** After a plain `uv sync`, neither `rasterio`
   nor `jupyter_core` is importable. The group holds: `jupyterlab`,
   `ipywidgets`, `ipyleaflet`, `matplotlib`, `numpy`, `pandas`, `pyproj`,
   `requests`, `rasterio`, `geopandas`. `ipyleaflet` ships its JupyterLab 4
   extension prebuilt, so no `jupyter labextension` step is needed; `pyproj`
   arrives with `geopandas` but is declared because this module imports it
   directly.

10. `notebooks/README.md` states, in English and in under a page: the two
    commands from EXP-001 → Reproduction, that the data domains are not in the
    agent sandbox allowlist so the measurement is run by a person, where outputs
    go, and that everything under `notebooks/` is exploratory and outside the
    ADR-003 layer contracts.

11. The full gate passes: `uv run pre-commit run --all-files`.

12. **Extent geometry, with exact values.** These are the figures the notebook's
    map selector reports back, so they are specified rather than left to taste:

    - `to_projected` returns the **envelope of the four reprojected corners**,
      not the two reprojected corners. A longitude/latitude rectangle is not a
      rectangle in a projected CRS, and taking only two corners silently loses
      ground on two sides.
    - `snap_outward(bbox, grid_m)` moves each edge outward to the nearest
      multiple of `grid_m`, so the result always contains the input.
      `snap_outward((400100.0, 4800050.0, 401000.0, 4800900.0), 128.0)` is
      exactly `(400000.0, 4800000.0, 401024.0, 4801024.0)`.
    - `extent_report` returns `width_m`, `height_m`, `area_km2`, `width_px`,
      `height_px`, `tiles` as `(cols, rows)`, `exact_fit`, `geodesic_width_m`,
      `geodesic_height_m` and `skew_m` — the last being the easting difference
      between the two western corners after projection, which is zero for an
      already-projected extent and non-zero for a geographic one. For the
      snapped extent above with `gsd_m=0.25` and `tile_px=256`: `width_m` and
      `height_m` are `1024.0`, `width_px` and `height_px` are `4096`, `tiles`
      is `(16, 16)`, `exact_fit` is `True` and `area_km2` is `1.048576`.
    - `exact_fit` is `False`, and nothing raises, when the extent does not
      divide into whole tiles. A non-fitting extent is a report, not an error:
      the reader decides whether to snap.
    - `extent_env_lines` returns exactly the two lines
      `GEO_DECAY_BBOX=min_x,min_y,max_x,max_y` and
      `GEO_DECAY_BBOX_CRS=<crs>`, ready to paste into EXP-001 → Configuration.
    - `save_extent` writes `out_dir / "extent.json"` holding the bbox, the CRS,
      the report and a UTC timestamp.

    **This is georeferencing, and `Acceptance tests` is still `no`** — a
    deliberate deviation from the rule in `.agents/roles/orchestrator.md`. The
    code is throwaway instrumentation outside `src/`; the same maths becomes a
    contract with acceptance tests in Sprints 8 and 10, where ADR-004 fixes the
    tile size and the snap grid. The numeric assertions above are what carries
    the weight here, and the verification command runs them.
