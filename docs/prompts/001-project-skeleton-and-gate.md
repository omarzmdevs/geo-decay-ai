## Specification

- `pyproject.toml`, PEP 621:
  - `name = "geo-decay"`, `requires-python = ">=3.12,<3.13"`, build backend
    hatchling. `[tool.hatch.build.targets.wheel] packages` lists the four
    `src/geo_decay_*` directories explicitly.
  - `[dependency-groups] dev` holds `ruff`, `mypy`, `import-linter`, `pytest`
    and `pre-commit`. Black is not used anywhere.
- `.python-version` contains exactly `3.12`.
- Ruff: `target-version = "py312"`. Lint rules include at least `E`, `F`, `I`,
  `B`, `UP` and `TID`, with `[tool.ruff.lint.flake8-tidy-imports]
  ban-relative-imports = "all"` (TID252). `ruff format` is the only formatter.
- MyPy: `strict = true`, `python_version = "3.12"`, `files = ["src", "tests"]`.
  Handoff 003 adds `scripts` when that directory holds Python files.
- Pytest: `testpaths = ["tests"]`, `--import-mode=importlib`, `--strict-markers`.
- import-linter: `root_packages` lists the four packages, and
  `include_external_packages = true`. There are exactly the four contracts of
  ADR-003:
  1. **layers**: `geo_decay_delivery` > (`geo_decay_application` | `geo_decay_data`)
     > `geo_decay_domain`. Application and data are independent siblings of the
     same layer.
  2. **independence**: `geo_decay_application` and `geo_decay_data`.
  3. **forbidden**: `geo_decay_domain` must not import any of `osgeo`, `rasterio`,
     `pdal`, `geopandas`, `fiona`, `sqlalchemy`, `psycopg`, `fastapi`, `torch`,
     `ultralytics`, `mlflow`, `dvc`.
  4. **forbidden**: `geo_decay_application` and `geo_decay_data` must not import
     `fastapi`.

  If import-linter rejects a forbidden module because it is not installed, stop
  and report it. Do not install it and do not drop it from the list.

## Acceptance Criteria

1. `.python-version` is exactly `3.12`.
2. `uv.lock` exists, and `uv lock --check` passes.
3. `uv sync --locked` succeeds from scratch.
4. Every `src/geo_decay_*` package has a `py.typed` marker, and
   `tests/acceptance/.gitkeep` exists.
5. `uv run lint-imports` reports `4 kept, 0 broken`.
6. `pyproject.toml` and `uv.lock` contain no reference to Black.
7. The full ADR-005 gate passes.
8. `git status --short` shows only the files listed above.

## Verification Command

```bash
grep -qx '3.12' .python-version \
  && uv lock --check \
  && uv sync --locked \
  && for p in domain data application delivery; do test -f "src/geo_decay_$p/py.typed" || exit 1; done \
  && test -f tests/acceptance/.gitkeep \
  && uv run lint-imports | grep -q '4 kept, 0 broken' \
  && ! grep -qi 'black' pyproject.toml uv.lock \
  && uv run ruff check . && uv run ruff format --check . && uv run mypy \
  && uv run lint-imports && uv run pytest \
  && git status --short
```
