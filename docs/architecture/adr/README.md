# Architecture Decision Records (ADR)

> An ADR is created whenever a significant architectural or technical decision is made. Each record captures the context, decision, alternatives, and consequences.

## Index

No ADRs have been created yet. They will appear here as the project evolves.

## Naming Convention

`adr-NNN-short-title.md` (e.g. `adr-001-detection-model.md`)

## Template

Use [adr-template.md](adr-template.md) as a starting point for new records.
